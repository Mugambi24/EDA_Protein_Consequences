This is an existing, incomplete multi-module EDA analysis workbench.
The biological model is anchored to the published human EDA-A1 protein FASTA.
The nucleotide model, genomic loci, RNA counts and variant cases are simulated.
Do not use the output as clinical evidence. The exact scientific task brief is
supplied separately as instruction.md and must be written by the task author.

Long-range calibrated phasing: /data/phase_graph_assay.json and /data/phase_graph_protocol.txt; supply --phase-graph and write phase_graph.json.
