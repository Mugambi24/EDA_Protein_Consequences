Synthetic EDA long-range allele-phase graph challenge (no patient molecule data)

Input `phase_graph_assay.json` keys: assay_id (string), synthetic (true), calibration (rows), cases (rows). All count triples have nonnegative integer `cis`, `trans`, `ambiguous`. For a calibration row, `batch_id`, `standard_id`, `replicate_id`, and `known_relation` (same/opposite) identify replicated known-phase controls. A case row has `case_id`, ordered unique `loci` (10-12 site IDs; otherwise reject nonzero), `anchor` equal to the first locus, and `edges`. Each edge has `left`, `right` (distinct case loci), `batch_id`, `replicate_id` (globally unique across every case and batch in the entire assay), and `counts`. The same allele's phase orientation is represented by bit 0 or 1, anchored at first-locus bit 0. The physical sign of phase is otherwise arbitrary.

Estimate independently for each batch the probability of a `cis` signal conditional on SAME and OPPOSITE true orientation from all calibration rows of that batch/relation: (sum cis + 0.5)/(sum cis + sum trans + 1.0). The `ambiguous` count carries no phase information. It is possible for cis signals to be *less* likely for truly same-phase links in a particular batch; do not assume a batch label is accurate or that a local majority identifies phase. If both calibration relations are not available for any used batch, reject input nonzero.

Conditional on the true bit parity of the linked sites, each edge contributes a binomial log likelihood: cis_count*log(q_parity) + trans_count*log(1-q_parity). Assume independent edges conditional on phase. All 2^(N-1) binary assignments with anchor bit 0 have uniform prior. Compute the normalized posterior distribution across these assignments using numerically stable log-sum-exp (exact enumeration or mathematically equivalent exact inference). Compute the marginal probability `p_opposite_anchor` that each site's phase bit is 1, and `map_posterior` for the single maximum-posterior complete assignment. Ties in the MAP assignment go to the lexicographically earliest bit vector (anchor first). Disconnected and weakly informed sites retain posterior uncertainty. A site receives `phase_bit` 0 if p<=0.05, 1 if p>=0.95, or null otherwise; anchor is always 0. `quality_flag` is `resolved` only if all sites have non-null bits, else `partial`. Report all probabilities rounded to six decimals and in [0,1].

Grading compares reported probabilities with an independently enumerated exact posterior on each withheld dataset. Required absolute per-site marginal error is <0.03; per-case whole-configuration MAP posterior error is <0.025; mean absolute marginal error is <0.01. Independently, mean Brier score against planted phase bits must be <0.08: Brier = sum over all sites (p_opposite_anchor - planted_bit)^2 / number_of_sites, computed separately on sealed and hidden sets. The planted bits remain verifier-only; they are not given to the solver. The withheld panels also contain both confidently resolved and uncertain sites, assessed using the 0.05/0.95 call rules. These numerical limits apply only to this synthetic phase assay.

Output `phase_graph.json` exactly `assay_id` and sorted `records`. For each `case_id`, record exactly `case_id`, `anchor`, `loci`, `map_posterior`, `quality_flag`; `loci` is ordered as input, each item exactly `locus_id`, `phase_bit` (integer 0 or 1, or null), and `p_opposite_anchor` (six-decimal float). No hidden truth, likelihood oracle, or known phase answers are present in the agent-readable data. The task uses synthetic truth and an independent exact-posterior verifier. It is not clinical haplotype interpretation.
